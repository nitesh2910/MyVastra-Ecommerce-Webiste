# 🛍️ MyVastra – Ecommerce Website

**MyVastra** is a full-stack e-commerce web application built with **Python** and **Django**. It allows users to browse products, manage a shopping cart, and simulate a full online shopping experience.

## 🚀 Features

- Product catalog with categories
- User registration & authentication
- Shopping cart management
- Admin dashboard (via Django admin)
- Responsive frontend with HTML/CSS/JS

## 🛠 Tech Stack

- **Backend**: Python, Django
- **Frontend**: HTML, CSS, JavaScript
- **Database**: PostgreSQL
- **Hosting**: https://myvastra-ecommerce-webiste.onrender.com/

## 📦 Installation

```bash
git clone https://github.com/nitesh2910/MyVastra-Ecommerce-Webiste.git
cd MyVastra-Ecommerce-Webiste
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
